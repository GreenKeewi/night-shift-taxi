# Night Shift

A lightweight, keyboard-first 2D taxi arcade game. Endless generated cities, traffic, fares and parking challenges.

## Play

Open the GitHub Pages site and press Enter.

- WASD / arrow keys: drive
- S / down: brake, then reverse
- Space: brake
- Esc / P: pause
- H: handbook
- L: low-power mode
- M: sound
- R: roadside assist

Use arrows or W/S and Enter in menus. Pickup and drop-off happen automatically when you park correctly in the marked bay.

## Stack

Plain HTML, CSS and JavaScript with Canvas 2D. No framework, backend, package install or build step. Scores and settings stay in the browser.

Serve this folder with any static HTTP server for local development. GitHub Pages publishes directly from the root of main.
